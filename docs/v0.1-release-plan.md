## Task 9: Fix QNN/Qualcomm false-positive in hardware probe

**Objective:** QNN shows as "available" on machines without Qualcomm hardware.

**Steps:**
1. Read `src/server/services/olive/qnn.ts` → understand what `probeQnn()` checks
2. Likely issue: the probe checks if QNN EP is loadable in ORT or if the Python package installs, not whether Qualcomm NPU hardware exists
3. Fix: gate QNN "local accelerator" status on actual hardware evidence:
   - Windows: check for Qualcomm device via WMI or `QnnHtp.dll` in standard paths
   - If no hardware detected: QNN should still appear as "Export & platform targets" (cross-compile), NOT as "Local accelerators"
4. Update `getProviderAvailabilityBlock()` or the probe to differentiate "SDK available" from "hardware present"

**Verification:** On a non-Qualcomm Windows machine, QNN no longer appears as a local accelerator. It may still appear as an export target.

**Verification:** UI text is visibly more readable. No layout overflow or truncation regressions.

## Task 11: Production hardening pass

**Objective:** Strip dev artifacts and add minimal security/performance for a release build.

**Steps:**
1. **Remove server sourcemap:** In `package.json` build script, remove `--sourcemap` from the esbuild command
2. **Add security headers:** `pnpm add helmet` → add `app.use(helmet({ contentSecurityPolicy: false }))` in `server.ts` after JSON parser, before routes. Disable CSP (local app loads scripts from self).
3. **Strip client console.log:** Remove the 2 `console.log` calls in `src/lib/owrExportConfigs.ts`
4. **Enable Brotli:** Uncomment the brotli `compression()` plugin in `vite.config.ts`. Update express-static-gzip config: `enableBrotli: true`, `orderPreference: ["br", "gz"]`
5. **Add X-Robots-Tag:** `app.use((_req, res, next) => { res.setHeader("X-Robots-Tag", "noindex"); next(); })` — prevents indexing if accidentally exposed

**Verification:** `pnpm build && pnpm start` — response headers include helmet defaults + X-Robots-Tag. No `dist/server.mjs.map` in dist/. Assets served with `.br` when client supports it.
