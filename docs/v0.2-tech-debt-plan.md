# Olive Studio v0.2 — Tech Debt & Agent Foundations (Revised)

> **Goal:** Eliminate structural debt blocking the v0.3 stateful agent. The primary blocker is the per-call subprocess spawn for MCP communication (~500ms overhead). Secondary goals: maintainability improvements and quality hardening.
>
> **Key revision:** The discriminated union passes migration (original Task 2) is downgraded. The MCP tools already provide the agent's abstraction layer (`validate_ui_state_recipe`, `get_quantization_strategy`, etc.). The agent never touches UIState.passes directly. A lightweight typed-accessor approach gives 80% of the DX safety with 10% of the migration cost.
>
> **Mode:** Default + Autopilot. One PR per task (or logical group). CI is the gate.
>
> **Depends on:** v0.1 shipped (current `main`).

---

## Background

- MCP server is Python FastMCP, stdio transport (default), launched via `run.py` → `python -m olive_mcp_server`
- Current client spawns fresh `python -c` per batch. Circuit breaker (3 failures → 30s cooldown) mitigates but doesn't fix latency
- Only 2 consumers: `routes/mcp.ts` (single tool) and `oliveMcpKnowledge.ts` (batch for AI chat)
- Official SDK: `@modelcontextprotocol/client` (v2, split package) provides `StdioClientTransport`
- `helmet` with CSP is already in server.ts (added during v0.1 prep, CodeQL alert #69)
- The flat `UIState.passes` bag works fine for agents via MCP tools

## Phase A: Critical Architecture (blocks v0.3 agent)

### Task 1: Persistent MCP stdio connection

**Objective:** Replace the per-call `python -c` subprocess spawn with a persistent stdio child process using the MCP protocol. Warm tool calls should complete in <50ms instead of ~500ms.

**Steps:**
1. `pnpm add @modelcontextprotocol/client`
2. Create `src/server/services/mcp/persistentClient.ts`:
   - On first call: spawn `python -m olive_mcp_server` (reuse `getMcpPython()` + `buildPythonEnv()`)
   - Use `StdioClientTransport` for JSON-RPC stdio connection
   - Expose same public API: `callOliveMcpTool(name, args)` and `callOliveMcpTools(requests[])`
   - Keep child process alive between calls; reconnect on crash/exit
   - Connection state machine: `idle → connecting → connected → crashed → reconnecting`
3. Integrate circuit breaker:
   - Track connection health (process alive + responsive), not per-call success
   - Process crash: `recordFailure()`, enter cooldown, next attempt after 30s spawns fresh
   - Tool-level errors never trip the breaker
4. Handle graceful shutdown:
   - Express close / SIGTERM: kill child, await exit
   - Unexpected child exit: auto-reconnect after cooldown
5. Replace the inline `python -c` script in `client.ts`:
   - New client calls tools via JSON-RPC `tools/call` over stdio
   - Remove Python script string generation
   - Keep `getMcpPython()`, `buildPythonEnv()`, `mcpServerDir()` as shared utilities
6. Consumers unchanged (same `callOliveMcpTool`/`callOliveMcpTools` signatures)

**Tests:**
- Connection state machine (spawn → connected → crash → reconnect)
- Breaker integration (3 spawn failures → open → cooldown → probe)
- Tool call serialization (JSON-RPC request/response)
- Warm call latency < 50ms (mocked process)
- Graceful shutdown kills child

**Verification:** `curl -X POST localhost:3000/api/mcp/tool -d '{"toolName":"get_olive_passes","args":{"filter":"quantization"}}'` returns in <50ms (warm).

## Phase B: Maintainability

### Task 2: Lightweight typed pass accessors

**Objective:** Add per-domain accessor functions that narrow `UIState["passes"]` into typed objects. No migration of the flat bag at the store/API/MCP boundary.

**Steps:**
1. Create `src/lib/passAccessors.ts`:
   - `getConversionConfig(passes)` → `{ enabled, format, sourceFormat, opset, ioTypes } | null`
   - `getQuantConfig(passes)` → discriminated union by method (AwqConfig | GptqConfig | PtqConfig | ...)
   - `getPruningConfig(passes)` → `{ enabled, sparsity, type, method, criteria } | null`
   - `getPeftConfig(passes)` → `{ enabled, method, diffusionLora } | null`
2. Round-trip test: `structuredToFlat(flatToStructured(DEFAULT_PASSES)) === DEFAULT_PASSES`
3. Optionally migrate 1 inspector as proof-of-concept

**Verification:** TypeScript compile error if accessing method-specific fields on wrong variant.
